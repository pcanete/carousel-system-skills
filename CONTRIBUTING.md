# Contributing

Contributions are welcome when they improve evidence quality, narrative craft,
portability, security, QA, or real-world usefulness.

Before opening a pull request:

1. Keep both skills independently installable.
2. Do not add private client data, credentials, fonts, photos, or unlicensed media.
3. Preserve the boundary between analyzing a reference and producing a new piece.
4. Update documentation and versioning when behavior or contracts change.
5. Run `npm test`.

Use synthetic, public-domain, or explicitly authorized fixtures. Changes to
`slides.json` or `carousel.config.json` must update both the documented schema
and behavioral tests.
