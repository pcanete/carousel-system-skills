# Security Policy

Never include credentials, private client strategy, personal data, proprietary
media, licensed fonts, unpublished copy, or client photos in issues, pull
requests, fixtures, or example outputs.

Do not upload client material to anonymous hosting services to bridge connector
limitations. Use assets already present in an authorized account, direct secure
uploads, or a storage location explicitly approved by the user.

For sensitive vulnerabilities, use GitHub private vulnerability reporting when
available. Otherwise contact the maintainer through the repository owner's
GitHub profile before public disclosure.

Users remain responsible for authorization, copyright, trademark, privacy, and
data-handling obligations for every analyzed or produced piece.
