# Instalación de cliente

Preparar esta capa una vez por marca. Respetar una estructura canónica existente; usar `clients/<dominio>/` únicamente como convención cuando el workspace no tenga otra.

## Fuente de ideas

Localizar el atlas, banco de contenidos o fuente equivalente dentro del workspace. Si el usuario puso ClickUp u otro sistema en alcance, se puede consultar y canonizar el resultado en la ubicación acordada. No convertir datos externos en archivos permanentes si el usuario solo pidió inspeccionarlos.

Si no existe una fuente, proponer una versión mínima: territorios, preguntas recurrentes, formatos y criterios de selección.

## POV editorial

Explicitar:

- qué sostiene la marca;
- qué evita afirmar;
- tono y nivel de evidencia;
- límites éticos o regulatorios;
- ejemplos aprobados y contraejemplos.

Las reglas universales de oficio viven en el skill. Las posturas propias viven en la capa del cliente.

## Sistema visual

Crear o localizar `brand/carousel/carousel.config.json`, fuentes y logo. Leer [esquemas.md](esquemas.md).

El responsable de marca aprueba el sistema visual. Si se infiere desde assets existentes, rotularlo como borrador y señalar cada supuesto. No buscar logos, fuentes o fotos fuera del alcance autorizado.

## Condición de preparación

La producción puede comenzar cuando existan:

- input concreto para la pieza;
- POV suficiente para evaluar el guion;
- configuración visual válida o plantilla Canva autorizada;
- aprobación editorial del texto antes del render final.

Una fuente de ideas completa es útil, pero no debe bloquear una transformación puntual cuando el usuario ya aportó el contenido.
