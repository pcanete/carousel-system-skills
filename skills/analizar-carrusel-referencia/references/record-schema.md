# Esquema de ficha

Usar solo las secciones que tengan evidencia. No inventar campos para completar la plantilla.

```markdown

- Autor / cuenta:

## Secuencia slide por slide

> ...

> ...
```

## Síntesis de cuenta

Actualizar `accounts/<cuenta>.md` únicamente desde fichas ya registradas. Incluir:

- alcance y cantidad de muestras;
- territorio editorial observado;
- fórmula narrativa recurrente;
- rasgos confirmados y variables;
- aprendizajes transferibles;
- elementos que no deben copiarse;
- próxima evidencia útil.
